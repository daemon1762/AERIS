   - Normal BACK path schedules geographic projection + terrain-colour preparation
     through the shared AERIS GeneralCompute worker scheduler.

   - Reset/cancel marks the single batch non-committable and lets already-running
     workers retire before any successor can reuse Entry scratch arrays.
   - Adds [CP3.5_GATE2_PARALLEL] aggregate runtime evidence.
