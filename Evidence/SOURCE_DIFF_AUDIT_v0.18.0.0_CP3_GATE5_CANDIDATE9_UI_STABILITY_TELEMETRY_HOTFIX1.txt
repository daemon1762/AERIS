USER VIDEO OBSERVATION:

ROOT CAUSE / PERFORMANCE:
- PreloadStatus previously delegated to preloadBuilder.SnapshotStatus() on every getter access.
- AERISWindow PRELOAD UI is Unity IMGUI; Layout/Repaint/input passes can execute the draw path multiple times per rendered frame.
- SnapshotStatus calls AERISTerrainPreloadDatabase.SnapshotBodies(), traversing tileIndex.Values under indexSync, then performs per-body pending/target calculations, sorting and allocations.
- Candidate 9 caches display-only PreloadStatus for 0.25 s (4 Hz), with immediate invalidation after explicit user mutations.
- Other potentially cache-walking SYSTEM diagnostic snapshots (terrain/resident/map/corridor) are display-rate cached at 4 Hz.
- AERISWindow.Draw() and DrawPreloadOnly() keep their first-line hidden-state returns, so these display snapshot paths do not run when the window is closed.

UI GEOMETRY CONTRACT:
- Active AERIS non-AIRFIELDS-selection buttons use explicit width+height and non-wrapping/clipped button styles.
- Main/SYSTEM tab column counts no longer change at width thresholds.
- MASTER, PRELOAD selectors, AIRFIELDS category/action buttons, LAND selectors, AP/NAV/TAKEOFF and helper buttons are fixed geometry.
- Sole variable-size exception: SYSTEM > AIRFIELDS airport/runway selection rows (airfieldRowButtonStyle).
- LAND airfield selector is fixed; it is not part of the exception.
- AERISNavigationDisplay buttons already use explicit Rect geometry; Candidate 9 additionally locks the shared button style to no-wrap/clip.
- Legacy AA GUI is unreachable from the current AERIS host and its Gate-5-frozen source tree remains byte-identical.
