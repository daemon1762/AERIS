# 省再起動実機テストカード — AIRFIELDS 0件カテゴリ

KSP起動は1回でよい。

1. SYSTEM → AIRFIELDSを開く。
2. 件数0のカテゴリを確認する。
3. 0件カテゴリの見出しがグレーアウトされ、クリックできないことを確認する。
4. 0件カテゴリの直下に `None.` や巨大な空白がないことを確認する。
5. 件数1以上のカテゴリは従来どおり展開・折りたたみ・詳細表示できることを確認する。
6. AIRFIELDSを閉じて再度開き、0件カテゴリが閉じたままであることを確認する。
7. Preload FULL→STOP→STANDARD復帰は既存試験結果を維持し、今回のUI試験では再実施不要。

合格条件：0件の全カテゴリが無効化され、空子レイアウトを生成せず、非0件カテゴリに退行がない。
