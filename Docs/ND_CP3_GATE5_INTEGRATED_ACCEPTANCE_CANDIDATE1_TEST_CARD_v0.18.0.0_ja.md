# ND / CP3 Gate 5 最終試験カード

1. Main Menu → Space Center → Flight。初期AIRFIELD/RWYがNONEを確認。
2. ND AUTO。Terrain AUTO。TRACK UP。5→10→20→40→80→160 kmを各10秒。
3. NORTH UPへ変更し、20 kmで60秒。
4. Terrain TOPO→REL→OFF→AUTO。ND AUTO→OFF→AUTO。
5. 250〜350 m/sでTRACK UP、360°以上旋回。
6. 39.5 km未満→40.5 km超→40.0 km付近→39.5 km未満の順でAltitude Gateを確認。
7. 空港/RWYを手動選択しLAND ARM→10秒以上→DISARM。
8. Flight→Space Center→Flight。
9. 別天体Flightへ移り、30秒以上待つ。可能なら元天体へ戻る。
10. Active Flight合計30分以上。60分ならExtended。
11. 終了後、`AERISFlightControl`フォルダをZIP化して提出。

必須映像確認：黒欠け0、クソコラ0、地理ズレ0、Map Lockずれ0。
