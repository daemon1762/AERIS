# AERIS12 v0.16.2.0 Adaptive Terrain ND 実機試験カード

## 1. 基本表示

1. LANDをARMせず固定翼機で離陸する。
2. 水面が青、陸地が相対高度色、海岸線と等高線が表示されることを確認する。
3. ND移動・リサイズ・ズームを行い、可読性と保存を確認する。

## 2. 品質プリセット

SYSTEM > OPTIONSでECO/BALANCED/HIGH/ULTRAを順に選ぶ。

- 地形密度と更新速度が段階的に変化する。
- 青い水面、警戒色、施設記号、LAND表示は消えない。
- 切替中に古い地図が新しい地図を上書きしない。
- フリーズ、周期的な大きなGC、AP/FBW停止がない。

## 3. 更新FPS

AUTO/10/20/30/45/60を順に選ぶ。

- Terrainの更新は航法シンボルより低頻度でも正常。
- LANDのLOC/GSと自機表示が設定に応じて滑らかに更新される。
- AUTO時、重い場面では実効FPSが低下し、安定後に急激な往復をせず段階回復する。

## 4. AUTO負荷適応

1. AUTO品質＋AUTO更新にする。
2. 軽い機体と重い機体、ND小サイズと大サイズで比較する。
3. SYSTEM > OPTIONSの`ND effective`表示を確認する。
4. 負荷悪化時は更新率が先に低下し、継続時だけ品質も低下することを確認する。
5. 瞬間的な一度のカクつきで設定が連続往復しないことを確認する。

## 5. LAND Overlay / Focus

1. KSCまたはIslandを選択し、空中でLAND ARMする。
2. `◐`でOverlay/Focusを切り替える。
3. Overlayは地形＋滑走路＋LOC＋GS、Focusは危険地形＋LAND幾何になる。
4. `CONTROL PILOT`が維持され、操縦介入しない。

## 6. FDI Terrain警告

安全な地形と回復余裕を確保する。NDに大きな警告文字を重複表示せず、FDIへ赤文字で最重大状態だけが表示されることを確認する。

## 7. スレッド安全性

- Scene変更、機体再読込み、ND非表示/再表示、品質連打後も例外がない。
- KSP終了時にプロセスが残留しない。
- Worker例外が発生してもAP/FBW/Protectは継続する。
