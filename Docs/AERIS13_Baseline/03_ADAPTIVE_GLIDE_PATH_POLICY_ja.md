# 方向別・可変グライドパス方針

状態: 次世代認証器の必須設計契約  
現行v0.17.0.2への実装変更: なし

## 1. 方針判断

3.0°は標準値であり、絶対値ではない。滑走路全体に一つの角度を持たせず、物理滑走路の各進入方向へ独立した角度と認証結果を持たせる。

初期の自動探索範囲は次とする。

```text
3.0° → 3.1° → … → 6.0°
```

安全条件を満たす最小角を採用する。最も急な角度を選ぶ設計にはしない。

2.5～2.9°は、自動障害回避の候補にしない。角度を下げるほど通常は地形余裕が減るためである。この範囲を使う場合は、手動精密定義、十分な長さ、完全な回廊検査、機体別の安定進入実証がそろった例外に限る。

6.0°も万能な上限ではない。機体の安定降下能力がそれより低ければ、その機体に対する上限を下げる。6.0°で安全回廊が成立しなければ、その進入方向は不合格とする。

## 2. 認証単位

認証キーは最低でも次を含む。

```text
body
airfield stable id
physical runway stable id
approach direction stable id
geometry fingerprint
provider/version fingerprint
terrain/static fingerprint
selected glide angle
certification algorithm version
```

09と27、AとBは別レコードにする。一方向だけ合格することを許容する。

## 3. 必須の三次元回廊

現行の「中心線16点、250～8000 m」だけでは不足する。次の全項目を検査する。

1. **縦方向**  
   閾値手前から少なくとも12 kmを、最大50 m間隔で連続評価する。急な地形変化部は適応的に細分化する。
2. **横方向**  
   中心線だけでなく、機体分散、滑走路幅、測量誤差を含む複数の横断線を持つ回廊にする。
3. **地形**  
   PQS標高を使い、隣接サンプル間の最大地形を保守的に包絡する。
4. **人工障害物**  
   Static、Collider、Renderer bounds等の上端を回廊と交差判定する。読めない場合は合格にせず`PENDING`または`FAILED`へ倒す。
5. **閾値周辺**  
   TCH、変位閾値、滑走路手前の崖・堤防・建造物を別の高密度領域で検査する。
6. **進入復行**  
   閾値通過後の復行上昇回廊、旋回開始制約、安全高度までの地形・障害物を検査する。
7. **滑走路面と停止余裕**  
   表面連続性、傾斜、使用可能長、ロールアウト端を検査する。進入が安全でも停止できなければ機体適合は不合格。

## 4. 余裕の扱い

単一の「最低10 m」だけを安全保証にしない。必要余裕は、測量誤差、地形解像度、Static境界誤差、機体の垂直追従誤差を合算して決める。

初期の試験用目安:

```text
required_clearance(d) =
  max(
    10 m,
    3 × vertical_uncertainty + 5 m,
    min(30 m, 10 m + 0.01 × d)
  )
```

`d`は閾値からの距離[m]。これは実飛行データで調整する出発値であり、最終保証値ではない。近距離ではTCHとの整合を保ち、遠距離では30 m以上の余裕へ増やす。

## 5. 角度選択アルゴリズム

各進入方向で次を行う。

1. 滑走路幾何と測量方式を確定する。
2. 3.0°で地形・障害物・復行回廊を検査する。
3. 不合格理由が「角度上昇で解消可能な縦方向余裕不足」の場合だけ0.1°増加する。
4. `MultipleGeometrySolutions`、`ThresholdUnresolved`、横方向侵入、復行不能等を角度変更で隠さない。
5. 最初に全回廊条件を満たした角度を候補とする。
6. 機体適合ゲートを通す。
7. 合格なら角度、最低余裕位置、制約機体条件、指紋を保存する。
8. 6.0°までに成立しなければ、その方向だけを不合格にする。

## 6. 機体適合ゲート

幾何学的に安全でも、機体が安定して飛べなければ使用禁止。

必要降下率は概ね次で求める。

```text
vertical_speed = ground_speed × tan(glide_angle)
```

判定には最低でも次を使う。

- 設定進入速度での必要降下率
- 安定降下で維持できる推力範囲
- AoA、ピッチ、失速余裕
- 乱気流・制御誤差を含む経路追従余裕
- フレア開始高度と必要ピッチ変化
- 接地速度と必要停止距離
- 横風制限

機体が選択角度へ適合しない場合、滑走路方向の幾何証明は残してよいが、その機体に対するLAND適格性は不合格にする。

## 7. 失敗時の方向別処置

| 状況 | 処置 |
|---|---|
| 3.0°で十分な余裕 | 3.0°を維持 |
| 地形高のみが不足 | 0.1°ずつ上げて再評価 |
| Static障害物が上昇で回避可能 | 上昇後に全回廊と復行を再評価 |
| 横方向へ障害物侵入 | 角度だけで通さず、その方向を不合格 |
| 閾値または中心線が曖昧 | 測量をやり直し、角度探索を開始しない |
| 6.0°でも不合格 | その方向を閉鎖 |
| 機体が必要降下率を維持不能 | その機体に対して不適格 |
| 片方向だけ不合格 | 反対方向の合格を保持 |

## 8. ログ契約

各方向について次を一行で出力する。

```text
AIRFIELD / RUNWAY / DIRECTION
geometry fingerprint
method
candidate angles tested
selected angle
minimum clearance and position
obstacle count
missed-approach result
aircraft eligibility
final state and failure code
```

「CERTIFIED」だけの記録は禁止する。何を証明した認証かを段階表示する。
