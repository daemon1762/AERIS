# 実機試験カード — Manual Calibrated Runway Separation / Preservation Hotfix 1

1. Build identity末尾が`MANUAL CALIBRATED RUNWAY SEPARATION PRESERVATION HOTFIX 1`であること。
2. AIRFIELDS起動直後、`CERTIFIED — AUTOMATIC / PROVIDER`と`USER CALIBRATED — MANUAL`が別枠で、両方閉じていること。
3. 既に端点を失ったKolaは、実滑走路の両端で改めて`MARK A`、`MARK B`すること。
4. 再測量完了後、Kolaの2方向が`USER CALIBRATED — MANUAL`にのみ表示されること。
5. 同じ方向が通常CERTIFIED枠へ重複表示されないこと。
6. NDへ両方向が表示されること。
7. 手動校正済み詳細では`CHECK HERE`が表示されず、保護説明と`MARK A / MARK B / CLEAR`だけが表示されること。
8. 再測量、カテゴリ開閉、シーン移動、再起動を行ってもA/B端点とND表示が維持されること。
9. 手動校正を変更する場合のみ`CLEAR`を押し、再度A/Bを記録できること。
10. ログに`PLACEMENT MISMATCH QUARANTINED`が手動校正済み方向について出ないこと。
