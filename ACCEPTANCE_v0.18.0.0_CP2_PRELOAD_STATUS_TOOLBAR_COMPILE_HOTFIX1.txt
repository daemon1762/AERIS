USER NATIVE COMPILE FAILURE
---------------------------
Terrain/AERISTerrainTileSystem.cs(1435,41): CS0117
AERISTerrainDisplayMode does not contain a definition for Auto.

ROOT CAUSE
----------
AERISTerrainDisplayMode declares Automatic, Topographic, Relative and Off.
RefreshTerrainRequestGeneration() alone referenced the nonexistent Auto member
when settings was null. Static brace and definite-assignment checks did not
validate enum member names.

FIX
---
- Replace AERISTerrainDisplayMode.Auto with AERISTerrainDisplayMode.Automatic.
- Extend the compile regression to parse the enum declaration, enumerate every
  AERISTerrainDisplayMode.<member> reference in all C# sources and reject any
  undeclared member.
- Build display/package metadata identifies Compile Hotfix 1.
- No intentional Terrain behavior, Toolbar behavior, AP, LAND or NAV change.
