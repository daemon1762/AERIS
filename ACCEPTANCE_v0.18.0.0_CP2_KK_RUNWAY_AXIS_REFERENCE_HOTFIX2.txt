ROOT CAUSE

snapshot.DeclaredHeadingDeg. For KK/SLE, DeclaredHeadingDeg commonly represents
the static model-instance orientation, not an internally rotated runway mesh.
This rejected valid non-0/180-degree runways as AbsolutePlacementInvalid.

- Use LaunchAnchorHeadingDeg as the independent broad world-space axis reference.
- Keep measured runway-surface PCA as the authoritative physical axis.

  launch-reference sanity gate.

- Rename diagnostic field to AxisReferenceErrorDeg.
